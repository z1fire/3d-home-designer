How to use

Floor plan (left)

  • Room tool — drag out a rectangle. Shape tool — click corners, click the first one (or press Enter) to close.
  • Select tool — drag a room to move it, drag a corner dot to reshape, drag furniture to move it.
  • Double-click a wall to add a corner. Alt+click a corner deletes it.
  • Door / Window — click on a wall to place, then drag it along the wall.
  • Wheel = zoom, middle-drag or space-drag = pan.

Keys

  • V select · 1 room · 2 shape · 3 door · 4 window · 5 paint
  • R / [ ] rotate the selected furniture 15° · Del delete · Ctrl+D duplicate
  • Ctrl+Z undo · Ctrl+Y redo · Ctrl+S save a file · 0 fit both views · F walkthrough
  • Type sizes as 12', 12' 6", 12.5 or 30" — all work.

3D view (right)

  • Left-drag orbit · right-drag pan · wheel zoom.
  • Select tool — click furniture to select, drag it across the floor.
  • Paint tool — pick a color on the left, click a wall / floor / ceiling.
  • Walk button — first-person walkthrough at eye height.

Ceilings

  • Select a room, then set the ceiling to Flat, Vaulted gable, Shed, Cathedral barrel or Tray.
  • Rise is how far the peak sits above the wall plate. Direction turns the ridge.
  • Gable ends are cut automatically into the walls.
